# Weichao Guo personal website

Static GitHub Pages package converted from the Google Sites export.

## Deploy

1. Create a GitHub repository, preferably `YOUR_USERNAME.github.io`.
2. Upload everything in this folder to the repository root.
3. Open GitHub repository Settings → Pages.
4. Choose `Deploy from a branch`, branch `main`, folder `/root`.

## Fonts

For closer typography and better access in China, put these local font files in `assets/fonts/`:

- `Lora-Regular.woff2`
- `Lora-Italic.woff2`
- `GoogleSans-Regular.woff2`
- `MaShanZheng-Regular.woff2`

Without them, the site falls back to local system fonts.

## Notes

Internal Google Sites links were rewritten to local GitHub Pages paths. Some Google Drive or Google-hosted external embeds may still need replacement with local PDFs/images.
